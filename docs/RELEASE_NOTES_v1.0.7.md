# E.D.I.T.H. v1.0.7

Поиск ошибок «того же рода», что нашлись в живой проверке.

## Исправлено

- **Потеря данных при сбое чтения.** Память, напоминания, очередь отложенных задач и список файловых операций при ошибке чтения
  (файл занят антивирусом или копировальщиком, оборван) превращались в пустой список, и следующее сохранение затирало всё.
  Теперь занятый файл перечитывается несколько раз, а нечитаемый сначала копируется рядом (`*.unreadable-ДАТА`), и только потом
  начинается пустой. Три теста.
- **Картинка прошлого запроса «прилипала» к следующему ответу** (до 45 секунд, например под «Убрала.» или под погодой). Теперь
  картинка принадлежит своему запросу.
- **Настройки со скрытыми ключами в комментариях.** Чтение и запись значений в конфигах находили ключ и в строке-комментарии
  (`// "enabled": false по умолчанию`) и могли менять не то. Строки-комментарии теперь пропускаются. Тест.
- **Настройки голоса** (`tts.json`) тоже допускают комментарии; раньше при них молча сбрасывались на встроенные.

## Проверено

- Ложные срабатывания маршрутизации на 24 бытовых фразах (заметки, ПК, выключение, напоминания, новости, приветствие, стоп,
  арифметика): лишних срабатываний нет.
- Тесты не меняют ваши данные (журнал, память, режимы окна).
- 949 автоматических тестов: Core 563, Speech 45, Audio 233, App 108.

## Не проверено

- Живая проверка голосом; чистая Windows 11 без SDK, Windows 10, шар под полноэкранной игрой, интерактивный проход «Установка.cmd».
