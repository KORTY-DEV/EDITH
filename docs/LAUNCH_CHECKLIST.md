# Запуск и проверка EDITH

Делать, когда видеокарта свободна (прогоны другого проекта закончились).

## 1. Сборка и запуск

Одна команда: собирает, закрывает старую EDITH, ставит новую в `C:\EDITHpp\current`,
обновляет ярлыки «EDITH» (рабочий стол, «Пуск») и запускает:
```
powershell -ExecutionPolicy Bypass -File C:\EDITH\scripts\Install-Edith.ps1
```
- Откат на прошлую версию: тот же скрипт с `-Rollback`.
- Дальше EDITH запускается ярлыком; повторный запуск просто открывает панель.
- Значок в трее: двойной клик — панель состояния, правый клик — поговорить, настройки,
  перезапуск, выход.
- Проверка без запуска: `powershell -ExecutionPolicy Bypass -File C:\EDITH\scripts\verify.ps1`.

## 2. Панель состояния — Ctrl+Alt+J

- «Сейчас: жду «Эдит»», строка «Ресурсы» с VRAM.
- Через ~20 с раздел «Системы»: микрофон, слово «Эдит», распознавание речи (**GigaAM v3**),
  локальная модель, диск, файлы моделей, журнал — всё зелёное.
- Внизу живая лента событий: каждое действие ниже должно в ней появляться.

`copy /Y C:\EDITH\config\wake.hybrid-v1.json C:\EDITH\config\wake.json`, затем запусти снова.
Отключить только подтверждение GigaAM: в `config\stt.json` добавь `"confirmWake": false`.

## 5. По желанию

- Выключение «когда агент закончит»: один раз выполни
  `powershell -ExecutionPolicy Bypass -File C:\EDITH\scripts\Install-AgentHook.ps1 -SettingsPath <файл настроек агента с хуками>`
  (добавляет хуки Stop и UserPromptSubmit, делает копию; свои названия агента вслух — в `config/agent-names.txt`).
- Характер EDITH: `C:\EDITH\config\persona.json` — правится без пересборки.
- Свои приложения: скопируй `config\apps.example.json` в `config\apps.json`.
- Вернуть старое распознавание: в `config\stt.json` поставь `"engine": "vosk"`.
