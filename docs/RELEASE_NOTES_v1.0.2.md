# E.D.I.T.H. v1.0.2

Исправления по живой проверке v1.0.1 (разбор журнала запросов и ответов).

## Исправлено

- **«Покажи …» и постоянные извинения «проблема с показом».** После успешного `find_image` модель зачем-то вызывала `show_image` с названием
  картинки вместо ссылки, получала ошибку и извинялась, хотя картинка уже была на экране. Теперь результат инструмента однозначен
  («ГОТОВО: картинка на экране, повторять не нужно»), повторный показ сразу после успеха не даёт ошибки, а в правилах характера
  сказано не извиняться после показа.
- **Устаревшая «лучшая видеокарта» и выдуманные названия.** Для «самый лучший / новейший / сейчас» поиск картинки теперь сам
  сначала делает поиск в интернете и отдаёт результаты модели, чтобы она выбрала настоящее название (раньше называла RTX 4090 или
  вовсе несуществующую RTX 590). Для запросов «покажи …» страницы сайтов не читаются (они закрыты или медленны, это давало
  «возникли трудности с доступом»). Сквозная проверка: «покажи мне самую лучшую видеокарту в мире» → RTX 5090 три раза из трёх.
- **Поиск картинки по общим словам.** «best graphics card in the world» ничего не находил: запрос теперь упрощается ступенями
  (без «best», «the», «world»; затем два последних слова; затем главное слово).
- **Бесконечный поиск по заметкам.** Один и тот же инструмент с разными словами мог вызываться 8 раз подряд (и всё равно «данных
  недостаточно»). Теперь после трёх вызовов ответ даётся по уже найденному. Тест добавлен.
- **Команда проглатывалась.** После «Эдит, покажи мне пейзаж» собственная фраза владельца, ещё не ушедшая из буфера, распознавалась
  как «Эдит» и отменяла только что начатую команду, приходилось повторять. Прослушивание «стоп / Эдит» поверх ответа теперь
  начинается через 2 секунды после команды.
- **Арифметика.** «Сколько будет 2026 минус 1999» модель считала как 2027. Сложение, вычитание, умножение и деление (цифрами и
  словами, с приоритетом × и ÷, десятичные дроби) теперь считаются точно, без модели; на ноль делить нельзя. 15 тестов.
- **Сводка.** Названия коммитов на английском больше не зачитываются буквами: в сводке они только если написаны по-русски.

## Проверено

- 926 автоматических тестов (App 96, Core 555, Audio 230, Speech 45), сборка Release.
- Сквозные прогоны на реальном мозге: запросы, которые не сработали в живой проверке, воспроизведены и пройдены; в журнале
  запросов тестовые записи удалены.

## Не проверено

- Живая проверка голосом (особенно «команда проглатывалась»: исправление основано на разборе журнала, не на повторе в реальной речи).
- Отрисовка найденной картинки в окне ответов (в журнале видно, что окно показывало картинки, поиск и загрузка проверены).
