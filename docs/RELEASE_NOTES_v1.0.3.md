# E.D.I.T.H. v1.0.3

Доработки по пунктам «не проверено» из v1.0.2.

## Исправлено

- **Заметки: «не посчитались векторы».** Вероятная причина: закрытие приложения во время расчёта убирало модель смысла из-под
  работающего потока. Теперь закрытие ждёт конец текущего расчёта, а оставшееся досчитывается при следующем запуске. Ошибка
  в журнал при закрытии больше не пишется.
- **Команда проглатывалась.** Правило «слушать «стоп / Эдит» только после того, как собственная фраза владельца осела в буфере»
  вынесено в отдельный класс с тестами (раньше было числами внутри окна приложения).
- **Тесты не ходят в настоящий мозг.** Проверки «мозг выключен» раньше обращались к облачному ключу и локальной модели этой
  машины и падали, когда те были доступны. Теперь тесты изолированы.

## Проверено

- Отрисовка найденной картинки в окне ответов: настоящее окно + настоящая картинка из Wikimedia Commons отрисованы в PNG
  (`BrainCheck --answer-shot`), картинка на месте, подпись и источник видны.
- Эмбеддер: 23 «трудных» текста (пустые, эмодзи, длинные, управляющие символы) и 8 потоков одновременно, результаты совпадают
  с одиночным расчётом; после закрытия вызов даёт понятную ошибку, не NullReference.
- Автоматические тесты: Core 557, Speech 45, Audio 233, App 96 (931).

## Не проверено

- Живая проверка голосом (что «команда проглатывалась» ушла в реальной речи).
- Ошибка «Object reference» у владельца не воспроизведена стресс-тестом; исправлена найденная вероятная причина.
- Чистая Windows 11 без SDK, Windows 10, поведение шара под полноэкранной игрой, интерактивный проход «Установка.cmd».
