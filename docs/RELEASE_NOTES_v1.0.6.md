# E.D.I.T.H. v1.0.6

## Исправлено

- **На вопрос про тёщу она ответила утренней сводкой.** Слово «привет» искалось внутри любого слова: «как её по**привет**ствовать»
  принималось за приветствие и получало сводку дня вместо ответа. Теперь приветствие — только короткая фраза («привет»,
  «добрый вечер», «доброе утро, Эдит»). Тест на длинные вопросы со словом «приветствовать».
- **Сводка дня:** предложения начинаются с заглавной буквы («Вчера за компьютером…», «Есть одна новая заметка»).
