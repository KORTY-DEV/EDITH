# E.D.I.T.H. v1.0.5

## Исправлено

- **«Эдит, убери окно» не срабатывало.** Журнал показал: распознавателю команды доходило только «окно» — первое слово терялось. Имя
  узнаётся с задержкой, а при слитной речи («Эдит убери окно») команда уже началась, и всё сказанное до открытия
  прослушивания пропадало. Теперь после имени команде отдаётся последняя секунда звука (имя из начала отрезается, как
  обычно). Это касается любой команды, сказанной слитно с «Эдит», а не только этой.
- **Запасные фразы для окна:** «убери картинку», «убери окошко», «убери фото», «уберите окно», а обрывок «окно» тоже прячет окно.
