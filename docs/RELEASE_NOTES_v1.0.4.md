# E.D.I.T.H. v1.0.4

Исправления по живой проверке v1.0.3.

## Исправлено

- **После «Эдит» она слушала меньше, чем нужно.** Файл `config/conversation.json` содержит комментарии, а читался без их поддержки:
  при первой же ошибке разбора все его значения молча заменялись встроенными (ожидание начала фразы 4 с вместо 6 с, и так
  для остальных настроек). Теперь комментарии допускаются, а ожидание после «Эдит» не бывает короче 5 секунд (по умолчанию 6).
  Тест проверяет поставляемый файл.
- **«Убери окно» → «Убрала», но окно оставалось.** Ответ «Убрала.» сам выводился в окне ответов и возвращал его на экран вместе с
  картинкой. Ответы на команды самого окна («убери окно», «выключи окно», «тихий режим» и т. п.) теперь только озвучиваются.
- **Картинка конкретного предмета.** Wikimedia Commons знает достопримечательности и вещи, но не игровую технику и новые
  устройства: на «Астрон Рекс» отдавала фото стенда игры. Теперь подпись найденной картинки сверяется с запросом (чужое фото
  отбрасывается), а если подходящего нет, поиск идёт в обычном поиске картинок в скрытом браузере (нужен компонент браузера
  из «Модели»). Проверено: «Astron Rex World of Tanks» → картинка нужного танка.

## Проверено

- 933 автоматических теста: Core 559, Speech 45, Audio 233, App 97.

## Не проверено

- Живая проверка голосом (длина ожидания после «Эдит», «убери окно» после показа картинки).
- Поиск картинок в интернете зависит от разметки сайта поиска: если она изменится, останется поиск по Wikimedia Commons.
- Чистая Windows 11 без SDK, Windows 10, шар под полноэкранной игрой, интерактивный проход «Установка.cmd».
