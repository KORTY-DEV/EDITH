# E.D.I.T.H. v1.0.8

Расширенный поиск ошибок: разбор встроенных фраз, времени, озвучивания чисел и внешних процессов.

## Исправлено

- **«Открой гугл переводчик» открывал просто гугл**, «открой блокнот и напиши…» просто блокнот. Фразы «открой / запусти» для
  встроенных программ и сайтов срабатывают только когда это вся команда (допускается «пожалуйста»).
- **«Погоди» принималось за вопрос о погоде** (искалось «погод» внутри слова). Теперь только слова «погода/погоду/погодой…».
- **«Не выключай» отменяло выключение в любой фразе** («не выключай свет в коридоре…»). Теперь только про компьютер или без
  продолжения.
- **Напоминания.** «Напомни в 7 вечера» ставило 07:00 утра с текстом «вечера»; «сегодня» становилось текстом напоминания.
  Теперь время суток не считается текстом. Добавлены «через два дня», «через сутки», «через двадцать пять минут».
- **Озвучивание чисел:** «-5» → «минус пять» (раньше «-пять»); дата `12.10.2026` читалась «двенадцать целых одна десятая»;
  «8 192 МБ» → «восемь сто девяносто два»; «15-го», «2-м этаже», «1990-х» читались с дефисом; «1,5 часа» → «полтора часа»,
  «2,5 часа» → «два с половиной»; ₽ → «рублей»; «RTX 5090» → «пятьдесят девяносто», а не «пять тысяч девяносто»;
  «3600X», «8b» — число и буква раздельно; «Code» → «код».
- **«Подвисание» из-за внешних программ.** Команда с большим выводом заполняла канал и выглядела как «превысила лимит времени»;
  `ollama list` при зависании замораживал окно моделей; зависший `git` держал библиотекаря. Теперь вывод читается параллельно,
  а ожидание ограничено по времени.
- **Распознавание имени могло «оглохнуть».** Если при проверке имени «Эдит» возникала ошибка, состояние «проверяю» могло остаться
  навсегда до перезапуска. Теперь любой сбой возвращает прослушивание.
