# E.D.I.T.H. v1.0.9

## Исправлено

- **Два преобразователя чисел, и работал худший.** В живом пути текст сначала проходил грубый числовой преобразователь ядра,
  поэтому улучшения озвучивания чисел не доходили до голоса: дата `10.10.2026` читалась «десять целых одна десятая.две тысячи…»,
  версия `1.0.7` — «один.семь», «+16» — «+шестнадцать» (знак `+` перед словом Silero принимает за ударение и коверкает слово).
  Теперь сначала работают правила озвучивания (даты, знаки, версии «один точка ноль точка семь», дроби, видеокарты, единицы),
  грубый преобразователь остаётся запасным.
- **Что не читается голосом:** эмодзи и значки (✅ 👍 😀), теги `<think>`, блоки кода, разметка ссылок (`[здесь](ссылка)` →
  «здесь»), `_` в именах файлов (`config_local` → «config local»), пробел перед знаком после эмодзи.
- **Списки** «1. … 2. … 3. …» читались одним потоком без пауз; теперь каждый пункт — предложение.
- **Сокращения:** «т.е.» → «то есть», «т.д.», «т.п.», «т.к.», «руб.»; «3 тыс.», «5 млн», «60 км/ч», «3 м/с» с правильным числом
  («три тысячи», «три метра в секунду»).
- **Деление на предложения при потоковой речи:** «300 тыс. руб. в магазинах» больше не рвётся посередине на «тыс.» и «руб.».
- **Время:** «в полночь» и «в полдень» в напоминаниях и выключении; даты `1/2/2026` и дроби «1/2», «3/4» читаются словами.
- Диапазоны «5–7 штук» по-прежнему читаются «пять–семь штук» (так говорят по-русски).

## Проверено

- 1000 автоматических тестов: Core 573, Speech 65, Audio 233, App 126 (в том числе 8 новых проверок очистки текста для озвучивания).
