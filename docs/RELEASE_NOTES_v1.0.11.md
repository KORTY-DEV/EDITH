# E.D.I.T.H. v1.0.11

## Исправлено

- **«Посмотри мой экран» описывало не тот экран.** EDITH снимала активное окно (то, где стоит курсор ввода), а при двух мониторах
  человек смотрит на другой: вместо открытого сайта она описала окно с чатом на втором мониторе. Теперь по умолчанию снимается
  весь монитор, где находится мышь. Можно сказать «другой экран» (второй монитор), «все экраны» (описывает каждый по очереди:
  «левый монитор: … | правый монитор: …») или «это окно» (только активное).
- **Описание «на глаз» ошибалось в названиях и ценах.** К снимку теперь добавляется текст, прочитанный распознаванием Windows
  (названия, цены, надписи точнее, чем по картинке). Окно-подсказка EDITH и шар в углу экрана в описание не попадают.
- **«Что на экране» / «посмотри на экран»** раньше читали текст активного окна. Теперь такие вопросы идут к мозгу, который описывает
  нужный монитор; «что в окне», «что за ошибка», «прочитай на экране» по-прежнему читают текст окна.

## Проверено

- На вашей конфигурации (два монитора 1920×1080) снимается монитор под мышью, описание верное (Ozon, пена монтажная, фильтры и цены).
  Проверка: `BrainCheck --screen-check ПАПКА describe`.
- 1012 автоматических тестов: Core 576, Speech 70, Audio 233, App 131.

## Не проверено

- Живая проверка голосом; три и более монитора; монитор с другим масштабом Windows (в проверке оба по 100%).
- Чистая Windows 11 без SDK, Windows 10, шар под полноэкранной игрой, интерактивный проход «Установка.cmd».
