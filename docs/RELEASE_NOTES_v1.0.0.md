# E.D.I.T.H. v1.0.0 — первый публичный релиз

Голосовой дворецкий для Windows 11: слово «Эдит», русский голос, память, браузер и экран, личный архив в Obsidian.

## Что внутри

- **Слух и голос.** Wake V3 с подтверждением GigaAM, Smart Turn, перебивание стоп-словом; Silero v5 с ударениями, паузами,
  числами/датами словами и английскими названиями по-русски; озвучка по предложениям; готовые фразы с диска.
- **Мозг.** GigaChat + запасная локальная модель (Ollama); ключ GigaChat вставляется в настройках и хранится зашифрованным.
- **Окна.** Живой шар (60 к/с, двигается в такт вашему и её голосу), окно ответов (двигается, растягивается, показывает картинки,
  «тихий режим»), одно окно EDITH с вкладками «Сейчас / Заметки / Память / События / Модели / Настройки».
- **Библиотекарь.** Подробные заметки по сессиям ИИ-агентов в Obsidian, хроника-оглавление, «Картина проекта» со снимком репозитория,
  поиск новых документов (только чтение). Включается переключателем (трей, голос, настройки), работает в паузах.
- **Пульс.** Время по программам и состояние репозиториев → «что нового?», итоги недели, сводка при первом приветствии.
- **Установка.** `Install-Release.ps1` (без .NET SDK), `Install-Models.ps1` (модели и окружение голоса из официальных источников),
  `Uninstall.ps1`, сторож перезапуска, автозапуск, обновление без потери данных.

## Что исправлено перед выпуском

- Библиотекарь больше не выключается сам при сохранении настроек. Причина: окно настроек показывало снимок, сделанный при открытии,
  и «Сохранить» записывало его поверх изменений, сделанных позже в трее или голосом (так же могла сброситься и «умная» пауза Smart Turn).
  Теперь сохраняется только то, что владелец сам изменил в окне; снимок обновляется после сохранения. Регрессионные тесты добавлены.
- Шар больше не «колотится» при речи: движение считалось от абсолютного времени, и любое изменение скорости давало скачки фазы;
  теперь фаза накапливается, а громкость микрофона и голоса нормируется автоматически и сглаживается.
- Шар двигается в такт вашему голосу сразу после активации.
- Мигающая консоль: сторож, который каждую минуту запускал PowerShell через планировщик, теперь запускается без окна.
- Одинокое «да» в ответ на вопрос EDITH больше не считается оборванной фразой.
- Карточка «Что нужно настроить» на первом запуске: чего не хватает и что делать.
- Установка из архива, обновление без потери данных, удаление; загрузчик моделей (найдена и исправлена ошибка: системный `tar` подменялся
  `tar` из Git).

## Проверено

- Сборка Release и **895 автоматических тестов** (App 89, Core 531, Audio 230, Speech 45) — все проходят.
- Архив: целостность (`unzip -t`), состав (228 файлов), отсутствие ключей, `.dpapi`, `.pdb`, личных путей и посторонних упоминаний; SHA-256 рядом.
- Установка из архива в тестовую папку **Windows PowerShell 5.1**, обновление поверх неё в **PowerShell 7.6**: пользовательские данные
  (память, ключ, скачанные модели, изменённые конфиги) сохранены, новые конфиги кладутся как `*.new`, `app\previous` создаётся;
  удаление с сохранением данных и с `-RemoveData`.
- Скачивание моделей из официальных источников в чистую папку: 8 проверенных файлов идентичны рабочим по SHA-256;
  окружение голоса поставлено с нуля (Python venv, torch для процессора, RUAccent), синтез Silero из него работает.
- Шар: 60,4 кадра/с в обычной работе (`data\diagnostics\orb-fps.txt`), около 0,22 мс процессорного времени на кадр.

## Не проверено (честно)

- Установка и запуск на чистой Windows 11 без .NET SDK (и в песочнице): на этом компьютере SDK установлен, пути жёстко заданы на
  `C:\EDITH`, поэтому полностью изолированный запуск невозможен. Проверен состав и скрипты, но не запуск приложения оттуда.
- Windows 10, другие микрофоны и видеокарты.
- Частота кадров шара под нагрузкой конкретных игр: измерения в игре нет (смотрите `orb-fps.txt`).
- Что мигающая консоль исчезла: устранена причина (окно сторожа), но наблюдение «глазами» в течение времени не проведено.
- Движение шара под реальную речь (ваш голос и её голос) проверено только расчётно и на заглушках, не на слух и взгляд.
