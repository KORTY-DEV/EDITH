# E.D.I.T.H. v1.0.12

## Улучшено: что она видит на мониторе

- **Точные названия вместо догадок.** К снимку добавляется список окон на этом мониторе: какая программа и какой заголовок (в браузере —
  название открытой вкладки). Сверху указано, что поверх всего и реально видно, ниже — что открыто под ним.
- **Выше качество картинки:** до 2000 px по длинной стороне и качество 85 вместо 1600 px / 75, мелкий текст читается лучше.
- **Приближение части экрана.** «Что написано внизу справа?» — берётся только эта часть в полном разрешении: левая/правая/верхняя/нижняя
  половина, центр, любой угол. Мелкий шрифт и значки читаются заметно лучше, чем на снимке всего экрана.
- **Распознанный текст остаётся в ответе.** На уточняющий вопрос («а сколько стоит вторая?») она отвечает по прочитанному тексту, а не по памяти.
- **Строже к выдумкам:** модели велено называть только видимое и честно говорить, если не разобрать; для магазинов, списков, таблиц
  и кода — точные названия, цены и числа (до 5 предложений вместо 4).

## Проверено

- На вашей конфигурации (два монитора): список окон сходится с реальным, приближение угла экрана работает (`BrainCheck --screen-check ПАПКА describe [область]`).
- Тесты: Core 576, Speech 70, Audio 233, App 131.

## Не проверено

- Живая проверка голосом; 3 и более монитора; другой масштаб Windows. Список окон не видит содержимое окон других пользователей и
  свёрнутых окон — только заголовки.
- Чистая Windows 11 без SDK, Windows 10, шар под полноэкранной игрой, интерактивный проход «Установка.cmd».
