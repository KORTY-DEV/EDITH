# E.D.I.T.H. v1.0.1

Исправления по результатам живой проверки v1.0.0 и более простая установка.

## Исправлено

- **Картинки.** «Покажи пейзаж / как выглядит видеокарта» не работало: модель выдумывала ссылку на картинку. Добавлен инструмент
  `find_image` — настоящий поиск свободных изображений (Wikimedia Commons, без ключа); `show_image` теперь только для путей и ссылок,
  которые назвал владелец или которые вернул другой инструмент. Если ничего не нашлось, можно попросить нарисовать (`draw_image`).
- **«Уточните» без ожидания ответа.** EDITH просила уточнить, но не слушала уточнение: окно ответа без «Эдит» открывалось только
  после вопросительного знака. Теперь оно открывается и после «Уточните, пожалуйста», «Скажите, какую именно…», «Назовите…»
  (и после вопроса в конце ответа); длится 9 секунд. Риторический вопрос посреди ответа окно не открывает. Тесты добавлены.
- **Заметки.** Ошибка «не посчитались векторы» теперь пишет место сбоя (раньше только «Object reference…»), чтобы её можно было найти.

## Установка проще

- Двойной щелчок по **«Установка.cmd»** в распакованном архиве: окно с вопросами по-русски проверяет Windows и .NET (при желании
  ставит через winget), устанавливает EDITH, скачивает модели и голос (ставит Python при необходимости), предлагает вставить ключ
  GigaChat, запускает EDITH. На большинство вопросов достаточно Enter.
- README начинается с установки в три шага.

## Проверено

- Все автоматические тесты, сборка Release; `find_image` — сквозной пример (запрос голосом → инструмент → картинка найдена и
  загружена); разбор всех скриптов установки в Windows PowerShell 5.1 и PowerShell 7.6.

## Не проверено

- Интерактивный проход «Установка.cmd» на чистой Windows 11 (на этом компьютере нельзя установить поверх рабочей `C:\EDITH`);
  логика вопросов и разбор скриптов проверены, установка из архива в тестовую папку — в v1.0.0.
- Показ картинки в окне ответов вживую (проверен поиск и загрузка, не отрисовка окна).
