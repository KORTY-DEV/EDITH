# E.D.I.T.H.

**Голосовой дворецкий для Windows**, который живёт на вашем компьютере: слышит своё имя, отвечает голосом, помнит вас,
открывает программы и сайты, читает экран и ведёт личный архив в Obsidian. Манеры в духе Джарвиса, язык общения — русский.

> Проект личный и живой: он делался под конкретного хозяина и его железо, поэтому честно читайте раздел
> [«Ограничения»](#ограничения). Всё настраивается конфигами.

## Что умеет

- **Слух.** Слово «Эдит» (акустическая модель + проверка распознаванием GigaAM), свободная речь, определение конца фразы
  (Smart Turn), стоп-слово поверх её собственного голоса. Шар на экране двигается в такт вашему голосу и её голосу.
- **Голос.** Silero v5 (четыре русских голоса) с автоматическими ударениями (RUAccent), числами и датами словами,
  английскими названиями по-русски; ответ озвучивается по предложениям, пока он ещё пишется. Готовые фразы играют с диска.
- **Мозг.** GigaChat (облако, бесплатная квота — см. [docs/GIGACHAT.md](docs/GIGACHAT.md)) с запасной локальной моделью через
  Ollama. Инструменты: состояние ПК, файлы (только через корзину и с подтверждением), приложения и окна, чтение экрана и
  описание картинок, собственный браузер (Playwright), поиск в интернете, заметки Obsidian (чтение), рисование картинок.
- **Память.** SQLite: факты о хозяине, итоги разговоров, поиск по словам и по смыслу (multilingual-e5-small, на процессоре).
- **Пульс.** В фоне считает время по программам (только имена процессов) и читает ваши git-репозитории, чтобы сказать
  «что нового». Всё остаётся на ПК.
- **Библиотекарь.** Разбирает сессии ИИ-агентов и подробно документирует их в Obsidian: заметка на сессию, оглавление-хроника,
  «Картина проекта» по этапам со снимком репозитория. Работает только в паузах (нет игры, видеокарта свободна), по умолчанию
  локальной моделью. Читает всё, пишет только свои файлы.
- **Окно ответов.** Почти прозрачная карточка на рабочем столе: ответ печатается, висит пока она говорит и гаснет;
  двигается и растягивается, показывает картинки. «Тихий режим» — только письменные ответы.
- **Надёжность.** Сторож перезапускает EDITH после падения; установка с откатом; автозапуск с Windows.

## Требования

| Что | Обязательно? | Зачем |
|---|---|---|
| Windows 11 (x64) | да | единственная проверенная система; Windows 10 не проверялась |
| [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) | да | запуск приложения (SDK нужен только для сборки из исходников) |
| Микрофон и колонки | да | голосовое общение |
| Python 3.11–3.13 | для голоса Silero | ставит `Install-Models.ps1`; без него говорит голос Windows |
| Интернет | при установке | скачивание моделей (~0,7 ГБ) и окружения голоса (~0,5 ГБ) |
| Ключ GigaChat | нет | быстрые облачные ответы; без него думает локальная модель |
| [Ollama](https://ollama.com) | нет | локальные модели (запасной мозг, библиотекарь) |
| NVIDIA GPU | нет | ускоряет локальные модели; голос, слух и память работают на процессоре |

Место на диске: около 3 ГБ без локальных LLM-моделей (они отдельно, 3–7 ГБ каждая).

## Установка из релиза (рекомендуется)

1. Скачайте `EDITH-1.0.0-win-x64.zip` и файл `.sha256` со страницы [Releases](https://github.com/KORTY-DEV/EDITH/releases);
   проверьте хеш: `(Get-FileHash EDITH-1.0.0-win-x64.zip).Hash` должен совпасть с содержимым `.sha256`.
2. Распакуйте архив (например, в «Загрузки») и выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\EDITH\Install-Release.ps1 -Autostart -Watchdog
   ```

   Скрипт ставит EDITH в `C:\EDITH`, делает ярлыки, кладёт рабочие конфиги рядом с примерами и запускает приложение.
   `-Autostart` — запуск вместе с Windows, `-Watchdog` — перезапуск после падения.
3. Скачайте модели и поставьте окружение голоса:

   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\EDITH\scripts\Install-Models.ps1
   ```

   Скрипт берёт модели из официальных источников, пропускает уже скачанное и умеет показывать, чего не хватает
   (`-Check`). Пока чего-то не хватает, на вкладке «Сейчас» окна EDITH есть карточка «Что нужно настроить».
   Собственный Chromium для браузерных инструментов — по желанию: `Install-Models.ps1 -Browser`.
4. Ключ GigaChat (по желанию, но желательно): значок EDITH в трее → **Настройки** → «GigaChat (облако)» → вставить ключ
   авторизации. Как получить его бесплатно — в [docs/GIGACHAT.md](docs/GIGACHAT.md).
5. Скажите «Эдит».

**Обновление:** распакуйте новый архив и снова запустите `Install-Release.ps1`. Ваши настройки, память, журнал, ключи и модели
не перезаписываются; новые версии конфигов кладутся рядом как `*.new`; прошлая версия приложения остаётся в `app\previous`.

**Удаление:** `powershell -ExecutionPolicy Bypass -File C:\EDITH\scripts\Uninstall.ps1` убирает приложение, ярлыки,
автозапуск и сторожа и оставляет ваши данные; `-RemoveData` удаляет и данные.

## Установка из исходников

```powershell
git clone https://github.com/KORTY-DEV/EDITH C:\EDITH
cd C:\EDITH
powershell -ExecutionPolicy Bypass -File scripts\Install-Edith.ps1 -Autostart -Watchdog   # нужен .NET 10 SDK
powershell -ExecutionPolicy Bypass -File scripts\Install-Models.ps1
```

Проверка: `powershell -File scripts\verify.ps1` (сборка + все тесты). Релизный архив собирает `scripts\Build-Release.ps1`.

## Настройка

Всё лежит в `config\`: `tts.json` (голос), `wake.json`, `brain.json`, `cloud.json`, `persona.json` (характер и обращение),
`conversation.json`, `library.json` (библиотекарь), `pulse.json`, `vault.json`. Основное можно менять в окне EDITH
(значок в трее → «Настройки…»; вкладка «Модели» — выбор и скачивание локальных моделей). Панель состояния: Ctrl+Alt+J.

Горячие клавиши: Ctrl+Alt+E — поговорить, Ctrl+Alt+J — окно EDITH, Ctrl+Alt+T — показать/убрать последний ответ.

Голосом: «убери окно», «покажи окно», «тихий режим», «говори вслух», «включи библиотекаря», «что нового?», «сводка»,
«нарисуй …», «покажи картинку …».

## Приватность

Голос и память остаются на вашем ПК. В облако (GigaChat) уходит только то, что вы спрашиваете, и найденные по вопросу заметки;
снимки экрана — только когда вы просите описать картинку. Библиотекарь по умолчанию работает локально. Ключ GigaChat хранится
зашифрованным средствами Windows (DPAPI, только для вашей учётной записи). Секреты, память и модели вне репозитория и архива.

## Ограничения

Честно о том, чего здесь нет:

- **Только Windows 11, только папка `C:\EDITH`.** Пути заданы жёстко; другой диск или Windows 10 не проверялись.
- **Проверено на одном компьютере** (Windows 11, GTX 1070 8 ГБ, Ryzen 5, 32 ГБ). На другом железе и с другим микрофоном
  чувствительность слова «Эдит» может понадобиться подстроить (Настройки → «Чувствительность к “Эдит”»).
- **Слово «Эдит»** обучено на голосе автора и другом шуме: у вас бывают пропуски и ложные срабатывания (дальше проверяет GigaAM).
- **Голос Silero v5** распространяется по лицензии CC BY-NC-SA 4.0 — только некоммерческое использование. Он не входит в архив:
  его скачивает ваш скрипт установки из официального источника.
- **Русский язык.** Распознавание, голос, характер и документация рассчитаны на русский.
- **Облако — по желанию.** GigaChat — сторонний сервис Сбера: условия, квоты и доступность не наши; в России и для физлиц.
- **Установка из архива проверена частично:** скачивание моделей и окружения голоса проверено в изолированной папке, сама установка
  и работа приложения — на машине автора. Подробности — в [release notes](docs/RELEASE_NOTES_v1.0.0.md).
- Проект активно меняется; настройки и формат памяти между версиями могут меняться.
