# E.D.I.T.H.

**Голосовой дворецкий для Windows**, который живёт на вашем компьютере: слышит своё имя, отвечает голосом, помнит вас,
открывает программы и сайты, читает экран и ведёт личный архив в Obsidian. Манеры в духе Джарвиса, язык общения — русский.

> Проект личный и живой: он развивается вместе с хозяином, поэтому часть настроек рассчитана на конкретное железо
> (GTX 1070 8 ГБ, Ryzen 5, 32 ГБ ОЗУ), но всё настраивается конфигами.

## Что умеет

- **Слух.** Слово «Эдит» (акустическая модель + проверка распознаванием GigaAM), свободная речь, определение конца фразы
  (Smart Turn), стоп-слово поверх её собственного голоса.
- **Голос.** Silero (пять русских голосов) с автоматическими ударениями (RUAccent), паузами, числами и датами словами,
  английскими названиями по-русски; ответ озвучивается по предложениям, пока он ещё пишется. Готовые фразы играют с диска.
- **Мозг.** GigaChat (облако, бесплатная квота) с запасной локальной моделью через Ollama; инструменты: состояние ПК,
  файлы (только через корзину и с подтверждением), приложения и окна, чтение экрана и описание картинок, свой браузер
  (Playwright), поиск в интернете, заметки Obsidian (чтение), рисование картинок.
- **Память.** SQLite: факты о хозяине, итоги разговоров, поиск по словам и по смыслу (multilingual-e5-small, на CPU).
- **Пульс.** В фоне считает время по программам (только имена процессов) и читает ваши git-репозитории, чтобы сказать
  «что нового». Всё остаётся на ПК.
- **Библиотекарь.** Разбирает сессии ИИ-агентов и подробно документирует их в Obsidian: заметка на сессию, оглавление-хроника,
  «Картина проекта» по этапам со снимком репозитория. Работает только в паузах (нет игры, видеокарта свободна), локальной
  моделью. Читает всё, пишет только свои файлы.
- **Окно ответов.** Почти прозрачная карточка на рабочем столе: ответ печатается, висит пока она говорит и гаснет;
  двигается и растягивается, показывает картинки. «Тихий режим» — только письменные ответы.
- **Шар.** Живой индикатор: вспышка при активации, реакция на громкость голоса, «думаю», «говорю».
- **Надёжность.** Сторож перезапускает EDITH после падения; установка с откатом; автозапуск с Windows.

## Требования

- Windows 11, .NET 10 SDK, PowerShell 5.1+
- Микрофон; видеокарта NVIDIA желательна, но не обязательна
- [Ollama](https://ollama.com) для локальных моделей (по желанию)
- Ключ GigaChat (бесплатный для физлиц) для облачного мозга (по желанию)
- Python 3.12 для голоса Silero и ударений

## Установка

```powershell
git clone https://github.com/KORTY-DEV/EDITH C:\EDITH
cd C:\EDITH
powershell -ExecutionPolicy Bypass -File scripts\Install-Edith.ps1 -Autostart -Watchdog
```

Установщик собирает приложение в `C:\EDITH\app\current`, делает ярлыки, кладёт примеры конфигов (`config\*.example.json`)
рядом как рабочие, запускает EDITH и (с `-Watchdog`) регистрирует сторожа. Прошлая версия хранится в `app\previous`
(откат: `-Rollback`).

Модели (Wake, Vosk, GigaAM, Silero, RUAccent, multilingual-e5, Smart Turn) скачиваются отдельно: список и скрипты — в
`docs/LAUNCH_CHECKLIST.md`. Ключ GigaChat: `scripts\Import-GigaChatKey.ps1 -EnvFile <файл с GIGACHAT_CREDENTIALS>`
(ключ хранится зашифрованным средствами Windows).

## Настройка

Всё лежит в `config\`: `tts.json` (голос), `wake.json`, `brain.json`, `cloud.json`, `persona.json` (характер и обращение),
`conversation.json` (поведение разговора), `library.json` (библиотекарь), `pulse.json`, `vault.json`. Часть настроек и выбор
моделей (кнопка «Модели…» с загрузкой) есть в окне «Настройки…» из значка в трее. Панель состояния: Ctrl+Alt+J.

Горячие клавиши: Ctrl+Alt+E — поговорить, Ctrl+Alt+J — панель состояния, Ctrl+Alt+T — показать/убрать последний ответ.

Голосом: «убери окно», «покажи окно», «тихий режим», «говори вслух», «включи библиотекаря», «что нового?», «сводка»,
«нарисуй …», «покажи картинку …».

## Структура

```
src/Edith.App       WPF-приложение: окно, шар, трей, настройки, инструменты мозга
src/Edith.Core      логика: память, диалог, библиотекарь, пульс, безопасность
src/Edith.Audio     микрофон, wake, распознавание, определение конца фразы, эхоподавление
src/Edith.Speech    озвучка: Silero, кэш фраз, числа и произношение
src/Edith.BrainCheck  проверки без микрофона (мозг, браузер, библиотекарь, шар)
tests/              тесты xUnit
scripts/            установка, проверка, обслуживание, сравнение моделей
docs/               план развития и чек-лист запуска
```

Проверка: `powershell -File scripts\verify.ps1` (сборка + все тесты).

## Приватность

Голос и память остаются на вашем ПК. В облако (GigaChat) уходит только то, что вы спрашиваете, и найденные заметки по вашему
вопросу; снимки экрана — только когда вы просите описать картинку. Библиотекарь по умолчанию работает локально.
Секреты хранятся вне репозитория (`secrets\`, `data\`, `models\` игнорируются git).
